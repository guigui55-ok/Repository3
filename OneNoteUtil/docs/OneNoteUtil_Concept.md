# 目的
OneNoteのデータ取得・更新を自動化する。

# 背景概要
1. OneNoteに自分の情報を共有するが、VsCode＋Copilotで作業するため、OneNote更新が２度手間となっており、この自動化のため。
2. OneNoteにある、多くのページのナレッジを調査・収集するため。

# 背景詳細
業務ではOneNoteを多用して、ナレッジの共有やこれまでのナレッジの蓄積を行っている。
現在はOneNoteプログラム上で手動検索とそれをローカルテキストにメモしながら作業を行っている。このメモをもとにCopilotと連携したりもしている。
また、業務についてのナレッジは、機能仕様書/設計書（word,excel）[Boxフォルダ内に格納されている]、OneNote、ローカルのメモ/フォルダ、など各所に散りばめられている。
将来的に、この散りばめられたナレッジを、Github Copilotで横断的に調査したい。
（ゆくゆくは調査もある程度自動化したい）
そのためにまず、OneNoteをローカル環境にmd化して配置しようと考えている。
本プロジェクトは、個人リポジトリ/個人プロジェクトで、業務ではないため、それを学習・試行するためのもの。

# 調査が必要な事項
* 他の方法も少しだけ調べておく（vbs、VBA、PowerShell、python）。簡単なサンプルなどがあってもよい。
    - 評価軸:「実装難度」「OneNote へのアクセス方法」「ローカル完結性」「保守性」「md 変換への向き不向き」
* まず、上記背景の１のためのサンプルを作成。そして、徐々にPGを拡充していく。
* Oneファイルの中に複数のブロックがあるが、これの読み取り方法、扱い方。

# 目的
本プロジェクトの目的は、上記の通りOneNoteの操作自動化とCoilotのオーケストレーションの検討・構築。

# 対象
* 使用環境・開発OS: Windows11
* 言語など: C# .Net Framework 4.8, コンソールアプリ
    - デバッグがしやすい言語を使用する
* OneNoteはサーバー上にある.oneファイルを想定
* 想定ユーザー: 開発者個人
    （業務用で個人的に使用するツール）
* oneファイル読み込み手法
    - COM経由で考えているが、要調査が必要（最小プログラムで検証する）

# 仕様
* oneファイルの読み込み、データの取得
    - できれば以下も対応したい（最小実装で確認）
        - 表
        - 画像
        - OneNote箇条書き
        - 同一ファイルに複数のテキストボックスを読み込み
            （Locationが小さいほうを先に読み込む）
* oneファイルの書き込み、データの更新
    - oneファイルの特定のセクション・ページを作成
        - データの書き込み（テキスト、表、画像、ファイル格納）
    - oneファイルの書式などを変更（タイトルなど）
    - できれば以下も対応したい
        - 表
        - 画像
* mdファイルに相互変換
    - OneNote→MD
    - MD→OneNote
