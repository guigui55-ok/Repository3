# Github Copilot オーケストレーション構築 基本構想書

この文書は、サンプルプログラムの実装前に、構想内容を整理し直したものである。  
現時点での目的・前提・要望・未解決事項を明確にすることを目的とする。


# 背景
ユーザー（私）はソフトウェアエンジニアで、をソフトウェアの開発をしている。
参画している案件では、1つの大規模なクライアント・サーバーシステム（複数Editionあり）の機能追加・改修を行っている。
作業の特徴として、小さな依頼（1機能の追加・回収）に一人の担当者をアサインし、その中で「事前調査・検討→概略見積→詳細調査→要求仕様→仕様書反映→詳細設計書→試験仕様書（テスト設計・項目作成）→試験実施」というフェーズを行う。

業務では GitHub Copilot(VsCode環境) を使用しており、作業の効率化を求められている。
（個人的にも学習したい。別件で自身でも小さな個人案件を対応したいと考えているため）
最終的に、Copilotによるオーケストレーションで、作業すべて～9割くらいの作業を自動化したいと考えている。
・9割くらいとは、調査実施/方針の検討/各種ファイルの作成をCopilotがすべて行い、そのレビューもCopilotが主に行う。（レビューはユーザーも行う）。そして、レビュー後の最終決定はユーザーが行うことを指す。
そして、作業すべてとは、上記すべての事を指す。
・最終目標としてはすべての作業の自動化だが、一旦9割の自動化をまず最初の目標とする。
・自動化したい工程は、本書の`# 対応したいフェーズ・作成する成果物`のすべてが対象。

まず個人で簡易的なツールを複数作りたいので、このツール作成とともにオーケストレーションも完成させていきたい。

        →基本は Lite-Ask、Lite-Editを使用する。
    - おおよそ一つの小規模プログラム作成につき 200～300程度で納められれば良いと考えている。（2026/08/07時点） （1つの作業につき20-30消費で、各フェーズを実施するとこれくらい諸日する想定）
