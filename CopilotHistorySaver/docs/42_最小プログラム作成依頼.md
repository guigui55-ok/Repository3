## デフォルトAgentだけでも可能か

4. ビルド

まで明示して依頼すれば、デフォルトAgentだけでも進められます。

ただし、デフォルトAgentは計画提示後、そのまま実装へ進む可能性があります。今回のように、**初めて内部形式を扱う試作**では、Planで一度止めてレビューした方がよいです。

## 別途エージェントを作る必要

現時点では、専用エージェントを新規作成する必要はありません。

今回だけのためにImplementation Agentを作ると、エージェント設計自体が追加作業になります。まずは次の手動オーケストレーションで十分です。

**Plan → ユーザーレビュー → デフォルトAgent → ユーザーレビュー**

実装作業を何度か経験し、毎回同じ制約を指定するようになった段階で、専用のImplementation AgentやReview Agentへ切り出すのがよいです。

結論として、今回は **Planで最小実装計画を作成し、確認後にデフォルトAgentで実装**を推奨します。Deep-Askは、追加調査が必要になった場合に使う位置付けでよいです。
