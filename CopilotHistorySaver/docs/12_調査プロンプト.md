CopilotHistorySaver_concept.md の内容を、実装方針に踏み込まずに「構想書の内容」だけとして分類すると、以下のように整理できます。

### 1. 確定事項
- 本プロジェクトの目的は、VS Code + GitHub Copilot の利用履歴のうち、ユーザーが入力したチャット内容を収集してファイルに保存すること。
- まずは「実装」ではなく「実現可能性の調査」を前提に、サンプルプログラムを作る方向である。
- 開発対象環境は Windows 11、Visual Studio / VS Code、C#、Console アプリとして整理されている。
- 開発環境・実行環境・調査対象環境は同じ前提で扱う。
- 収集対象として、質問内容のタイトル・本文・タグ・作成日時・回答数などが挙げられている。
- 収集の前提として、ローカル環境での利用を想定している。

### 2. 仮説
- Copilot Chat の履歴は VS Code / Copilot のローカル環境に保存されている可能性が高い。
- その保存先として、.vscode 配下や workspaceStorage 配下が候補として挙げられている。
- VS Code の各ワークスペース共通設定が Users フォルダに存在する可能性がある。
- そこから履歴情報を読み取れる可能性がある、という前提がある。
- もし保存形式が分かれば、質問内容を抽出・整理できる可能性がある。

### 3. 調査が必要な事項
- Copilot Chat の履歴が実際にどこに保存されるか。
- 履歴データの保存形式（JSON、SQLite、ログ、その他）。
- ワークスペースと履歴の対応関係。
- タイトル、日時、タグ、回答数などのメタ情報を取得できるか。
- 更新後も形式が維持されるか。
- 公式 API やエクスポート機能があるか。
- 読み取りが利用規約・社内規則・機密管理上問題ないか。
- 取得対象を特定フォルダ単位で絞れるか。

### 4. 要求
- ローカル環境でユーザーが入力した Copilot のプロンプトを収集する。
- 収集した内容をファイルに記録する。
- 可能であれば、回答内容も収集したい。
- サンプルプログラムで、質問内容のメタ情報を取得できるかを確認したい。
- 特定フォルダ内のすべての質問内容を収集できるかを確認したい。

### 5. 技術制約
- 対象環境は Windows 11 前提。
- 実装言語は C#、.NET Framework、Console アプリ前提。
- 公式な取得 API が見つからない可能性があるため、ファイルや保存形式の直接読み取りが前提になる。
- ローカル環境での利用を前提としているため、外部サービス連携は想定していない。
- 調査対象の環境と開発環境が同じ前提である。

### 6. 将来構想
- まずは調査・試作を行い、その後に通常のソフトウェア開発工程へ進める。
- 将来的には、ユーザーのレビュー作業を AI が支援する形に広げたい。
