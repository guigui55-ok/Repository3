# 第1段階のオーケストレーション

ユーザー
  ↓
Investigation Agent
  技術調査・影響範囲・不明点を整理
  ↓
ユーザー承認
  ↓
Planning Agent
  実装計画を作成
  ↓
ユーザー承認
  ↓
Implementation Agent
  承認された範囲だけ実装
  ↓
Review Agent
  計画との差異、バグ、テスト不足を確認
  ↓
ユーザー最終判断

まず、ユーザーが手動で運用する。
調査Agentを選ぶ　→出力を確認する　→Plan Agentを選ぶ　→実装Agentを選ぶ　→Review Agentを選ぶ
